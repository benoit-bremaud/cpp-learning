# Initial diagnostic

Work without generated solutions. Consult documentation if needed, but record where you needed help. A gap is placement information, not a failure.

## Tasks

1. Explain compilation and linking. Describe the difference between an undeclared function and a declared function with no linked definition.
2. Explain initialization, `const`, scope, value passing, and const-reference passing using your own examples.
3. Explain the contract and algorithm for a function that computes the minimum, maximum, and mean of a sequence. Define empty-input behavior without implementing it.
4. Explain why returning a reference to a local variable is invalid. Contrast an owning object with a non-owning pointer or view.
5. Describe how you would count word frequencies and return the most frequent word with a deterministic tie rule. State the complexity and container choice.
6. Explain what RAII and `unique_ptr` accomplish. Give a situation where `shared_ptr` would and would not be appropriate.
7. Describe what copying and moving a vector mean. Explain what `std::move` itself does.
8. Describe normal, invalid-input, and boundary test cases for task 3. Explain how you would investigate a crash using a debugger and sanitizer.

## Scoring and placement

Score each task 0 (cannot yet complete), 1 (partial or completed with substantial help), or 2 (correct and independently explained). Maximum: 16.

- 0–5: follow the full plan, revisiting stages 1–4 as needed.
- 6–11: use stages 1–3 as targeted revision and keep the remaining sequence.
- 12–16: attempt the early module exit criteria; skip only demonstrated material.

Regardless of the total, revisit stages 4–7 if lifetime, ownership, or move semantics remain unclear. Passing this diagnostic does not establish advanced competence.

Record your score, uncertainties, and examples in the progress tracker. Do not commit private data or credentials used in unrelated exercises.
